# Backlog — App Standard

This file is a parking lot, not implementation authority.

## Rule

A backlog item does not become active because:

- it is a good idea;
- Codex noticed it;
- the code is already open nearby;
- it would be convenient to do now;
- it appeared in a review comment that is not blocking the active gate.

Only the Review-Control Chat may promote an item into `PROJECT_SCOPE.md` / `CURRENT.md` after the required product decision.
